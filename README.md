# 覚えよ

日本史・世界史の年号暗記アプリ。Next.js 16 / React 19 / TypeScript。アカウントや外部APIは不要です。

## 起動と確認

```sh
npm install
npm run dev
```

http://localhost:3000 を開きます。

```sh
npm test          # データ・抽出・判定・共有履歴・移行・セッションのテスト
npm run build     # 型チェックと本番ビルド
npm start         # 本番サーバー
```

追加依存なしのヘッドレスChrome検証も用意しています。別ターミナルで `npm start -- --hostname 127.0.0.1 --port 3105` を起動し、`npm run test:browser` を実行してください。macOSのChromeを標準パスから起動します。他環境では `CHROME_BIN`、別ポートでは `HISTORY_BASE_URL` を指定してください。一時プロファイルを使用し、ユーザーのChromeプロファイルは操作しません。

実際に起動中の開発サーバーも、次のコマンドで検証できます。ホーム・問題一覧・学習記録のHTTP応答、直接表示、クライアント遷移も確認します。

```sh
HISTORY_BASE_URL=http://localhost:3000 HISTORY_SCREENSHOT=0 npm run test:browser
```

遷移の検証ではルート応答を意図的に保留し、待機表示・連打によるセッション重複の防止・結果の即時表示・表示後の維持を確認します。`HISTORY_NAVIGATION_ONLY=1 HISTORY_SCREENSHOT=0 npm run test:browser` でこの部分のみ実行できます。

トップ画面のスクロールも、ホイール・タッチ、出題範囲モーダルの各閉じ方、ブラウザの戻る・進む、終了確認中の画面移動で確認します。`HISTORY_SCROLL_ONLY=1 HISTORY_SCREENSHOT=0 npm run test:browser` でこの部分のみ実行できます。

## 待ち時間への対応

| 確認した箇所 | 対応 |
| --- | --- |
| 最終問題の手動・自動進行、途中終了 | 保存済みの解答から結果を即座に表示し、URLの切り替えを待たない |
| 学習・結果の動的URL | URLのIDをクライアントで取得し、画面表示のためだけのサーバー処理待ちを削減。学習中に結果画面を先読み |
| 学習開始・ホームと記録からの復習・結果からの再挑戦 | 遷移中のステータス表示、開始ボタンの準備中表示、操作の無効化と共通の重複防止 |
| ヘッダー・ホームに戻る・データがない場合のリンク | 未準備の遷移には読み込みステータスを表示。キャッシュ済みなら即座に切り替え |
| 学習中にメニューへ移動 | 非表示で保持される学習画面が原因で、移動後もスクロール禁止が残る問題を修正 |
| モーダルの閉鎖・履歴移動でホームへ復帰 | モーダルのスクロール禁止はネイティブの開閉状態にCSSで追従し、過去の禁止状態を復元しない。学習画面のロックは表示切り替え時に同期して解除 |
| 各ページの初回表示・保存履歴の読み込み | ヘッダーを維持した読み込み表示。履歴未取得時に空の記録を表示しない |
| 問題一覧の文字入力 | 入力の反映を優先し、検索結果の描画を遅延。変化していない一覧の再描画を省略し、検索中を表示 |

読み込み通知は画面・リンク間で1つに集約し、250ms未満の待ち時間では表示しません。一度表示した場合は最低300ms維持し、連続する処理でも表示を作り直しません。画面の切り替えやボタンの有効化は通知の表示時間を待ちません。背景のプレースホルダーは明滅させず、通知はスクリーンリーダーと動きを減らす設定に対応します。出題範囲モーダルは端末内のデータで開閉するため、操作を遅らせる待機時間は設けていません。

## 画面とURL

| 画面 | URL |
| --- | --- |
| 学習ホーム | `/` |
| 出題範囲（ホーム内モーダル） | `/#settings` |
| 学習 | `/study/<セッションID>` |
| 結果 | `/results/<セッションID>` |
| 学習記録 | `/records` |
| 問題一覧 | `/library` |

出題範囲は別ページにせず、ホーム内のモーダルで開きます。`#settings`はモーダルの開閉状態で、「戻る」で閉じ、「進む」や再読み込みで再表示できます。旧`/settings`は`/#settings`へ案内します。通常の画面移動はNext.jsのLink / Routerで行います。学習完了時は学習画面の履歴を結果画面に置き換え、戻る操作で不要な完了案内を挟まないようにしています。問題ごとの進行は同じURL内で更新し、ブラウザ履歴を増やしません。戻る・進むに対応し、設定・入力中の数字・紀元・進捗・解答結果は再読み込み後にも復元します。直近20セッションを保持するため、古いセッションや別ブラウザから開いた学習URLではデータなしの案内を表示します。

## 出題範囲

3つの方式は排他的です。非選択方式の値は復元用に保持し、抽出には適用しません。

- **単元から選択**：世界史21・日本史13グループ。大分類の一括選択、部分選択表示、小単元の複数選択、単元名検索。選択単元の和集合をIDで重複排除します。
- **地域×時代から選択**：11地域それぞれの時代区分を使用。地域タグと年号だけで判定し、単元所属には依存しません。「中国」は朝鮮・モンゴル・満洲などを含む東アジア史の学習範囲です。
- **全範囲ランダム**：単元・地域・時代・保存済みの出題順・科目均等化を無視し、対象をFisher–Yates法で一様にシャッフルします。星を抽選の重みに使いません。

学習ホームは科目・出題数・解答方式・優先度を1列で選び、そのまま開始できる構成です。対象数と学習開始ボタンのカードは画面下に固定し、スクロール中も操作できます。ページ下部にはカードに隠れない余白を確保しています。科目の下・解答方式の上に出題範囲を表示し、背景付きの選択欄から「出題範囲を細かく選ぶ」を開きます。選択した単元名や地域・時代は大きめの文字と強調表示で確認できます。復習への入口を下部に置き、記録の集計や最近の解答は上部メニューの学習記録画面で表示します。

優先度（★〜★★★★★）はホームの解答方式の下で直接選択できます。ホームで、「すべて」「★★★★★のみ」「★★★★以上」「★★★以上」の一括選択、星と「最重要」「重要」「標準」「やや発展」「発展・細目」のラベル付きチェックボックスを表示します。対象数は選択と同時に更新されます。

優先度エリアの下の「未出題を優先」をチェックすると、解答履歴のない問題を先に選び、不足する分だけ解答済みの問題で補います。全範囲ランダムでも有効で、科目の均等化より未出題の優先が先に適用されます。チェック状態は保存されます。

優先度（★〜★★★★★）と学習状況は全方式で絞り込めます。同じ分類内の複数選択はOR、分類間はANDです。デフォルトの星指定なしは全星を意味します。単元未選択や収録問題0件の場合は開始できません。

「苦手を優先」は「未出題を優先」の横で選択できます。苦手度が0を超える問題を先に選び、不足分は他の問題から補います。両方が有効なら未出題、苦手な問題、その他の順です。10・20・50・全問を選択し、対象数が足りないときは存在する分だけ出題します。

モーダルは単元または地域×時代などの出題範囲の選定だけを行い、「この範囲を使う」でホームに戻ります。科目・優先度・解答方式・出題数・優先指定はホームに置きます。範囲のリセットでこれらの設定は変わりません。プリセット機能は実装・保存データを残して非表示にしています。旧学習状況フィルターは読み込み時に優先指定へ移行し、表示できない条件で出題候補が絞られ続けないようにしています。

## 解答と履歴

- 完全年号、上の桁（下一桁表示）、上の桁（下二桁表示）、世紀の4方式。選択画面には1648年の具体例を表示します。`□□□□年 → 1648`、`□□□8年 → 164`、`□□48年 → 16`、`□□世紀 → 17` のように、枠と入力する数字を示します。
- 上の桁の解答では、入力した数字と固定数字を同じ書体・サイズ・色・ベースラインで連続表示。1648年なら `164` + `8` / `16` + `48`。
- 出題画面は表示領域の高さに収まる固定レイアウトです。問題文の長さによって入力欄やボタンの位置は変わりません。長文は問題文の領域内で文字サイズを調整し、長い解説は枠内のページ切り替えで最後まで読めます。スマートフォンのキーボードによる表示領域の変化にも追従します。
- 出題中は科目・時代や「上3桁を答える」などの表示を省き、プレースホルダーは常に `?`、入力上限は共通の6文字とします。入力幅は入力済みの数字だけに合わせ、正解の桁数を示しません。
- 年号が短い場合も最低1桁は解答します。57年の下二桁表示では上1桁の `5` を入力し `7` を固定表示。1桁の年は全桁を入力します。
- 「前／後」で紀元を指定。毎問「後」が初期値。紀元前221年の世紀は3、紀元前100年は1、西暦101年は2。紀元0年は扱いません。
- 語呂合わせ・備考がない問題は、正解の約1秒後に自動進行します。語呂合わせ・備考がある問題と不正解の問題は、Enter／次へで手動で進めます。二重解答・二重進行はセッションIDと問題位置で防止し、画面を離れるとタイマーを停止します。
- 世紀解答では正しい世紀を大きく、実際の年号を補足として小さく表示します。
- 出題画面の「ヒント」で、同年・同紀元の別の出来事を全登録問題からランダムに最大3件表示します。年号そのものは表示せず、該当なしの場合はその旨を表示します。選択したヒントはその問題の間は維持し、次問でリセットします。狭い画面ではページ切り替えで全文を確認できます。
- スマートフォンでは学習開始時の操作中に数値キーボードの表示を準備し、次の問題の入力へフォーカスを移します。正解後の自動進行では入力欄のフォーカスを維持します。
- 「わからない」は入力なしでも確定でき、不正解として履歴・苦手度・復習対象に反映します。正しい年号と備考を確認してから手動で次へ進みます。入力途中の数字は誤答として保存せず、「わからない」として記録します。
- 履歴は問題IDごとに共通管理。解答方式を変えても総解答・正解・不正解・直近の結果・連続正解・復習対象が共有されます。
- 苦手度は `max(0, 直近10回の誤答数 × 2 − 連続正解数)`。0を超える問題を復習対象にします。誤答で対象となり、連続正解で下がります。
- 「最近間違えた問題」は直近10回に含まれる過去7日以内の誤答。最近の解答100件も別途保持し、記録画面で直近15件を表示します。

## データの追加

| ファイル | 内容 |
| --- | --- |
| `data/events.json` | 問題データ |
| `data/sources/events-draft.txt` | 問題データの元になった年号ドラフト |
| `data/sources/japanese_history_years.csv` | 追加した日本史年号の原本（274項目） |
| `data/sources/japanese-history-import.json` | CSV全行の対応先・重複・優先度の理由・参考資料 |
| `data/sources/japanese-history-import-report.md` | 重複38項目、追加236件の評価、年号の扱いの確認記録 |
| `data/units.ts` | 単元グループ・小単元のIDと名称 |
| `data/regions.ts` | 地域・地域独自の時代ID、名称、開始年、終了年、順序 |
| `data/priorities.ts` | 星の表示と評価の定義 |
| `lib/types.ts` | 型定義 |
| `lib/events.ts` | 問題属性の検証 |
| `lib/study.ts` | 抽出・判定・履歴・セッション更新 |

`data/events.json` に次の形式で追加します。

```json
{
  "id": "wh-1648",
  "subject": "world",
  "name": "ウェストファリア条約",
  "year": 1648,
  "era": "CE",
  "dateType": "single",
  "unitId": "W13-02",
  "regions": ["europe"],
  "priority": 5,
  "period": "近世ヨーロッパ",
  "themes": ["外交史"],
  "source": "https://avalon.law.yale.edu/17th_century/westphal.asp"
}
```

- `id` は固定かつ一意。履歴とセッションがこのIDを参照します。
- `subject` は主所属の `japan` / `world`。日世共通問題は `subjects: ["japan", "world"]`（主所属を含む）を追加し、他科目の単元を `relatedUnitIds`、地域を `regions` に設定します。科目・単元・地域の抽出、一覧・復習・科目別集計は両科目に対応し、問題IDと履歴は1つです。科目均等化は主所属で行い、全体では重複出題しません。共通問題を含む科目別件数は単純に合計できません。
- `era` は `CE` / `BCE`。`year` は常に1以上の整数です。紀元前221年は `year: 221, era: "BCE"`。
- 主所属は `unitId` 1つ。必要なら `relatedUnitIds` を追加できます。同じ問題は1件として出題します。
- `regions` は地域IDの配列。複数地域を設定できます。日本史は `japan`。日世共通問題には日本と対応する世界史地域を設定します。東アジア周辺諸国は学習上の関連に応じ `china` を含めます。
- `priority` は1〜5。既存547問は `data/sources/new-stars.md` の評価を維持しています。追加236件は既存評価と公開の受験用年表・公的資料を照合し、項目ごとの理由・比較対象・出典を追加記録に保存しています。年号全桁を覚える優先度を表し、入試頻度の実測値ではありません。
- `note` は任意で、解答後と詳細画面に「語呂合わせ・備考」欄として表示します。年号右側の内容はすべてここに保存しています。`source` は今回の収録元では `draft`、外部資料のURLの場合だけ参照リンクを表示します。
- `draftLines` は元の `data/sources/events-draft.txt` に対応する行番号です。重複を統合した問題では複数行を保持し、テストで全項目の年号・紀元・備考を照合します。
- `answerPrecision` は `decade`（下一桁不要）／`hundred`（下二桁不要）。draftで指定された2問では完全解答モードでも指定桁だけを答え、他の数値入力モードでも指定以上の桁を要求しません。
- `dateType: "single"` だけを出題します。年代に幅がある場合は `range`（任意の `endYear` / `endEra`）、概算は `approximate` にして単一年号問題にしないでください。
- 単元IDは保存キーです。既存のグループ・小単元を並べ替えてIDを変更しないでください。
- 地域時代の抽出範囲は符号付きの年（紀元前は負数）、両端を含む区間です。境界は`data/regions.ts`に一元化しています。王朝の厳密な在位期間ではなく学習範囲の区切りで、「隋・唐」〜「五代・宋」は指定例に合わせ618〜1279年です。南北朝と室町、宋と元、明と清などの並立には区間の重複を許容しています。最初の先史範囲と最後の9999年は抽出の上下限で、画面では「先史」「現在」と表示します。
- 更新後は `npm test` と `npm run build` を実行してください。

## 保存データの移行

保存先は `localStorage` の `history-dates:v2`。初回にv2がなければv1を読み込み、既存の総解答・総正誤・直近履歴を引き継ぎます。旧モード別記録を再加算せず、既存の問題単位の合計から共通履歴に移行します。v1のキーはバックアップとして残します。

科目・解答方式・出題数・出題順・プリセットを引き継ぎます。旧単元名は小単元IDへ変換し、旧地域指定は先頭の1地域へ変換します。廃止した複合フィルター（大分類・テーマ・任意年範囲など）は新方式に持ち越しません。

## 収録内容と制約

[年号ドラフト](data/sources/events-draft.txt) の552項目をもとに547問（日本史27問・世界史520問）を収録しています。同じ出来事の5組（マラッカ占領、アイルランドの国家合同、アイルランド自由国の独立、ウェストファリア条約、第一メキシコ帝国成立）は説明を残して統合しています。年号未記載だった東遊運動は1905年で追加しました。年号はdraftの指定を採用し、教会大分裂の終了、靖康の変、マレー連合州などの出題文の誤記を修正しています。その後に指定された年号・表現の修正は、登録データとドラフトの両方に反映しています。問題IDとドラフトの対応行番号は維持しています。収録内容の歴史的事実を全面的に再検証したものではありません。

その後、`japanese_history_years.csv` の274項目から重複38項目を除いた236件を追加し、合計783問になりました。主所属は日本史263問・世界史520問。日世共通88問を含めると、日本史から選べる問題は276問、世界史からは595問です。近衛声明3件は指定により既存1件への重複として扱っています。年号の諸説・段階・暦の違いは出題文と備考で補足し、CSVの年は維持しています。詳細は[照合記録](data/sources/japanese-history-import-report.md)を参照してください。

語呂合わせ・備考は解答後と問題詳細に表示し、出題中は表示しません。CSVの備考も対応する新規・既存問題に保存しています。全単元に問題があるわけではなく、未収録の地域・単元では0問を表示します。

端末間同期・バックアップ、実機iOS/Androidでのソフトウェアキーボード操作は今後の確認・拡張対象です。保存は利用中のブラウザ内のみで、ブラウザのデータを消すと履歴や進行状態も消えます。
